This project is made with GDevelop, a beginner-friendly, low-code, free game engine, so even with just a bit of work anybody could figure out how to make their own maps.

Simply Drag and Drop different objects into the scene, set their size, set up that specific instance's information (Information about the Planet/Star/Moon/Space Station, what it orbits, etc.), and the engine will take care of the rest, including setting up the polar grid and label for the Star System.

The code is a little messy, but it works. If you want to modify the project more heavily then you are free to do so, as long as you credit the original project (or this repository) wherever you're posting that.
